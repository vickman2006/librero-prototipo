# Librero · prototipo navegable

Prototipo de una app para prestar libros entre amigos, con el kit de validación remota de andamio-dev. Las pantallas y los datos son de ejemplo (correos `@ejemplo.com`): no hay usuarios reales ni lógica de negocio.

- Probarlo: https://vickman2006.github.io/librero-prototipo/
- Enlace por rol: `#rol-dueno`, `#rol-amigo-ana` o `#rol-sin-cuenta` al final de la dirección.
- Ver el prototipo sin el panel de pruebas: `?autor`.
